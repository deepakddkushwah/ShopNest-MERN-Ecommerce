# 🛒 ShopNest Frontend Client

The user-facing Single Page Application (SPA) for **ShopNest**, architected with **React 18**, **Redux Toolkit**, and **React Router DOM**.

* **Author:** Deepak Kushwaha
* **Technologies:** React.js, Redux Toolkit, Context API, CSS3 Modules

## Scripts

* `npm start` or `npm run dev`: Starts the local React development server on port `3000`.
* `npm run build`: Generates production bundle inside `/build` directory.
